WETTER PLAUEN ALS SMARTPHONE-WEB-APP

Diese Dateien müssen auf einem HTTPS-Webspace veröffentlicht werden. Eine direkt auf dem Smartphone geöffnete HTML-Datei kann Live-Abfragen blockieren.

Empfohlen: GitHub Pages
1. Kostenloses GitHub-Konto anlegen bzw. anmelden.
2. Neues öffentliches Repository erstellen, z. B. wetter-plauen.
3. Alle vier Dateien aus diesem ZIP in das Repository hochladen.
4. Settings > Pages öffnen.
5. Unter Build and deployment: Source = Deploy from a branch.
6. Branch = main, Ordner = /(root), dann Save.
7. Nach wenigen Minuten wird eine HTTPS-Adresse angezeigt.
8. Diese Adresse auf iPhone/Android öffnen.

Zum Home-Bildschirm:
iPhone Safari: Teilen > Zum Home-Bildschirm.
Android Chrome: Menü > App installieren bzw. Zum Startbildschirm hinzufügen.
